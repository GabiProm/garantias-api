# Sistema de Gestión de Garantías

API desarrollada en .NET 8 con SQL Server para gestión de tickets de garantía.

## Funcionalidades

- Registro de tickets
- Gestión de componentes dañados
- Manejo de estados (abierto / cerrado)
- Búsqueda flexible por serie o inventario
- Lógica de negocio real

## Tecnologías

- ASP.NET Core
- Entity Framework Core
- SQL Server
- Swagger
